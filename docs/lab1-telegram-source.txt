Список и кортеж в Python - это два типа данных, которые используются для хранения коллекций данных. Однако они имеют несколько важных отличий:

1. **Список:**
   - Список - это изменяемый тип данных, который позволяет добавлять, удалять и изменять элементы.
   - Список хранит элементы в произвольном порядке.
   - Список можно изменять, добавлять и удалять элементы.

2. **Кортеж:**
   - Кортеж - это неизменяемый тип данных, который хранит элементы в произвольном порядке.
   - Кортеж не позволяет изменять его элементы.
   - Кортеж можно создавать с помощью круглых скобок (например, (1, 2, 3)) или с помощью функции tuple.

**Пример:**

```python
# Создание списка
my_list = [1, 2, 3, 4, 5]
print(my_list)  # Вывод: [1, 2, 3, 4, 5]

# Добавление элемента в список
my_list.append(6)
print(my_list)  # Вывод: [1, 2, 3, 4, 5, 6]

# Создание кортежа
my_tuple = (1, 2, 3, 4, 5)
print(my_tuple)  # Вывод: (1, 2, 3, 4, 5)

# Добавление элемента в кортеж (не изменяет кортеж)
my_tuple.append(6)
print(my_tuple)  # Вывод: (1, 2, 3, 4, 5)
```

### Объяснение

Список и кортеж в Python — это типы данных, которые используются для хранения коллекций элементов. Однако они имеют некоторые отличия:

- **Список** — это изменяемый тип данных, который позволяет добавлять, удалять и изменять элементы в процессе работы программы. Например, список может содержать элементы типа `int`, `str`, `list`, и т.д.

- **Кортеж** — это неизменяемый тип данных, который также содержит коллекцию элементов. Кортежы используются для хранения данных, которые не нужно менять, например, для сохранения информации о пользователе или координате точки на плоскости.

### Пример

```python
# Создание списка
my_list = [1, 2, 3, "hello", [4, 5]]
print(my_list)  # Вывод: [1, 2, 3, 'hello', [4, 5]]

# Создание кортежа
my_tuple = (1, 2, 3, "hello", (4, 5))
print(my_tuple)  # Вывод: (1, 2, 3, 'hello', (4, 5))

# Изменение элемента в списке
my_list[2] = "world"
print(my_list)  # Вывод: [1, 2, 'world', 'hello', [4, 5]]

# Изменение элемента в кортеже (не изменяется)
my_tuple[2] = "world"
print(my_tuple)  # Вывод: (1, 2, 'world', 'hello', (4, 5))
```

### Ответ на вопрос

Кортежы используются для хранения данных, которые не нужно менять, например, для сохранения информации о пользователе или координате точки на плоскости. Списки, наоборот, используются для хранения изменяемых данных, которые можно добавлять, удалять и изменять в процессе работы программы.

### Разница между Списком и Кортежем:

Запуск 12, temperature 1.0
Различия между списком и кортежем в Python следующие:

- Список это изменяемый тип данных:
  * Он может менять свои элементы при выполнении команд (выделяют по индексу).
  * Например, списки являются отличным выбором для хранения данных типа данных, которые мы хотим поменять. 
  * В Python список создается с помощью скобок: `my_list = [1, 2, 3]`
  * Для добавления, удаления или изменения элементов списка используется `add`, `remove` или `insert` функция соответственно.
  * Списки можно создавать с помощью цикла `for` следующим образом: 
    ```python
    my_list = []
    for i in range(10):
        my_list.append(i)
    ```
  * Также списки можно объединять и перекликаемыми использовать: 
     ```python
     my_list = [1, 2, 3]
     your_list = [4, 5, 6]
     same_list = my_list + your_list
     ```
    **Самопроверка:** Запустите `my_list.append('Hello')`, `your_list.append('Hello')`, `same_list.append('Hello')`, и убедитесь, что `my_list, your_list, same_list` все еще хранят `["Hello"]`.

Кортеж – это итерируемый неизменяемый тип данных:
  * Он не может меняться не только при выполненных команд, но и на каждом разбиении. Это хорошо известный пример, когда мы хотим хранить неизменяемые элементы, таких как цвета или названия погодных условий.
  * Например, кортежи создаются вводящими скобками: `my_tuple = (1, 2, 3)`
  * Некоторые операции с кортежами включают `iter` и `next` и `zip` и так далее, которые работают с кортежами, чтобы использовать только те элементы, которые нужен.

**Задание:** Сравните список и кортеж. Опишите разницу между ними при работе с числами и списками, который в списке можно добавлять, изменять и удалять.
